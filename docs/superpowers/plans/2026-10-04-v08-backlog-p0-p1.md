# Astra v08: plan de implementación

> **Para agentes:** sub-skill requerida: superpowers:executing-plans (ejecución en línea en esta sesión). Los pasos usan casillas (`- [ ]`). El proyecto no usa Git: no se inventan commits. La evidencia queda en `build/*.log` y `reports/*.json`, como en v07.

**Objetivo.** Aplicar B1, B2, B3, B4, B6 y B7 de la revisión técnica en una v08 nueva y entregarla completa: perfil QA y ZIP, con revisión independiente. Spec: `docs/superpowers/specs/2026-10-04-v08-backlog-p0-p1.md`.

**Arquitectura.**
- Los datos de balística y daño se fijan en un solo lugar de `build_plugin.py`, que usan tanto el build como el validador.
- El cuerpo Havok del virote se corrige con un parche binario de campos de tamaño fijo, mediante `scripts/nif_fisica.py` (Python puro). Ese módulo también provee los chequeos nuevos.
- El cero de mira es una función portable de `Core.cpp` con tests C++. `Plugin.cpp` solo la compone.
- El sonido lo reproduce Papyrus, después de `Launcher.Fire`.

**Stack.** Blender 4.4 + PyNifly 27; Python 3 (`parser_esm`, `nif_nodos`, `escritor_plugin` de vendor); compilador y ensamblador de Papyrus de Bethesda; CommonLibSSE-NG con MSVC 14.51, CMake y Ninja; MO2.

Comandos comunes (desde la raíz v08, PowerShell):

```powershell
$BLENDER='C:\Program Files\Blender Foundation\Blender 4.4\blender.exe'
python -B -m unittest discover -s tests -t .      # suite completa; EXIT 0 obligatorio
```
